# Finance Executive Summary Dashboard — Power BI

Interactive 3-page Power BI report analyzing sales, profit, and discount performance across products, managers, and regions.

## 🛠️ Tools Used
- Power BI Desktop
- DAX (calculated columns, measures)
- Excel (source data)

## 📊 Dashboard Pages
1. **Finance Report** — Total sales, profit KPIs, regional trends
2. **Discount Analysis** — Discount impact on profitability by product
3. **Profit Analysis** — Manager-wise and product-wise profit breakdown

## 💡 Key Business Questions Answered
- Which products generate highest profit margins?
- How do discounts affect overall profitability?
- Which managers contribute most to revenue?
- What are the regional sales trends?
